# here lies the respository for the UWaGMiP fire research project
We hope to create a simulator model that can be used for small wild fires and base if off of that of the Chautauqua wildfire that occured on February 28th 2026.
We plan to collect data and have this project be of use to others conducting research in wild fires perhaps even ones that pose a safety risk.
This simulator will likely be created with python code and members will have access to the GitHub as well as altering it.
